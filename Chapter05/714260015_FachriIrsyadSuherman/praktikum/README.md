## 🎸 Tentang Proyek
SKULL CRUSH FESTIVAL 2026 adalah portal web interaktif yang dirancang khusus untuk para metalhead. Website ini menerapkan sistem keamanan autentikasi sederhana di mana pengguna wajib melakukan login atau registrasi akun terlebih dahulu sebelum dapat mengakses katalog konser dan melakukan transaksi pembelian tiket.
