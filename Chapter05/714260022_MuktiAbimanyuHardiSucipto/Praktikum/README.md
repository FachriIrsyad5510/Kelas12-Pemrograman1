# Harbymo
Web restoran harbymo dengan warna desain cream dan orange

## Fitur
1. **Search** untuk mencari atau memfilter sesuai kategori
2. **shooping cart** menghitung total harga
3. **dark Mode** mengubah tampilan menjadi gelap

## Cara menjalankan
1. download file
2. Buka folder 
3. Jalankan file 'index.html'
